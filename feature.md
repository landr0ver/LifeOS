# Features

## [Kanban] Drag and drop card management
Create, edit, and reorder cards across columns with drag-and-drop support.

## [Kanban] Board and column management
Create multiple boards with customizable columns (e.g., Todo, In Progress, Done).

## [Habits] Daily habit tracking with streaks
Track daily and weekly habits, visualize streaks and completion rates.

## [Notes] Markdown note editor
Rich markdown editor for creating and editing notes with tags.

## [Notes] Knowledge graph visualization
Interactive force-directed graph showing connections between notes.

## [Notes] Full-text search
Search across all notes with PostgreSQL full-text search.

## [Calendar] Event scheduling
Create, edit, and view events in month and week views.

## [Calendar] Task-calendar integration
Link kanban cards to calendar events for deadline tracking.

## [GitHub] Repository issue and PR sync
Connect GitHub repos and sync issues/PRs to the kanban board.

## [GitHub] feature.md auto-sync
Automatically create GitHub issues from entries in feature.md.

## [AI] Claude-powered task suggestions
Get AI-suggested next actions based on current board state.

## [AI] Note summarization
Summarize long notes or groups of related notes using Claude.

## [AI] Smart note connections
AI-suggested links between related notes for the knowledge graph.

## [AI] Planning assistant chat
Conversational AI assistant for planning and brainstorming.

## [PWA] Offline support
Cache data for offline viewing with sync-on-reconnect.

## [Theme] 70s retro design system
Warm earth tones, clean typography, and retro-inspired UI components.

## [Auth] Single-user authentication
Simple password-based login for self-hosted single-user setup.
